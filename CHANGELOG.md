# 0.7.x

Патч вносит значительные улучшения в производительность и гибкость работы с Qdrant (явные режимы фузии, оптимизированные префетчи), исправляет проблемы сериализации сложных узлов LlamaIndex, унифицирует асинхронную типизацию и убирает устаревшие API-сигнатуры.

## Qdrant и векторный поиск

- Переписан класс _Request: убраны магические методы (__add__, __mul__), добавлены явные методы .hybrid(), .hsf() и .fuse() для объединения запросов.
- Внедрена поддержка трёх режимов фузии результатов: hsf, rrf, dbsf.
- Добавлен метод _resolve() для эффективной работы с префетчами и батчингом запросов.
- Дефолтные размеры батчей (upsert_batch_size, query_batch_size) зафиксированы на 64 (ранее были None).
- Возвращаемые коллекции унифицированы: везде используется list вместо абстрактного Sequence.

## Сериализация узлов LlamaIndex

- Полностью переписана логика конвертации узлов в записи Qdrant (llama_to_record / record_to_llama).
- Оптимизировано хранение: метаданные, текст и doc_id вынесены на верхний уровень, бинарный контент сериализуется через JSON (исправлена проблема с изображениями).
- Добавлена явная поддержка типов ImageNode, IndexNode, TextNode.
- Устаревший файл _nodes.py удалён, логика перенесена в _llama.py.

## Типизация и асинхронность

- Везде заменены AsyncIterator на AsyncGenerator в сигнатурах функций.
- Типы Sequence заменены на более гибкие Iterable (в _types.py, _parsers.py, util.py).
- В _responses.py проверка типов расширена до AsyncIterable.
- Убрано поле reasoning_effort из класса OpenAiLike.

## Утилиты и инфраструктура

- В tokenizer.py улучшено управление кэшем tiktoken: переменная окружения теперь устанавливается временно, добавлена корректная обработка неизвестных моделей через encoding_name_for_model.
- В synth.py в функцию репакинга промптов добавлен аргумент padding.
- Переход на loguru для логирования (вместо стандартного logging).

# 0.6.x

Патч представляет собой крупную архитектурную переработку: выделение нативного Qdrant-клиента без зависимости от LlamaIndex, введение единого типа Tokens для ответов, добавление собственного синтезатора с кастомным стримингом и обновление стека зависимостей.

## Единый тип токенов и ответы LLM

Введён новый заморозенный класс Tokens (_types.py), унифицирующий работу со строками и асинхронными потоками. Поддерживает await и итерацию.
Добавлена функция get_full_response() для сборки потока токенов в итоговую строку.
Рефакторинг _responses.py: unpack_response теперь возвращает (Tokens, list[NodeWithScore]). Добавлен tokens_from_response(), который автоматически извлекает Tokens из любых форматов ответов LlamaIndex (стриминг, Pydantic, агенты, синтезаторы).

## Редизайн Qdrant-хранилища

Класс переименован в Qdrant, полностью удалена прямая зависимость от LlamaIndex.
Упрощён API: методы add(records), retrieve(ids), query(dense, sparse, fuse), delete_by(), delete(), clear().
Заменена сложная логика гибридного поиска на композиционный класс _Request с поддержкой операторов +, *, .limit() и .unit() (нормализация оценок).
Убраны устаревшие форматы данных, ручная конвертация метаданных и функция _relative_score_fusion.

## Адаптер для LlamaIndex

Создан новый модуль qdrant_llama.py с классом QdrantVectorStore, который оборачивает новый нативный Qdrant для сохранения обратной совместимости с API LlamaIndex.
Выполняет автоматическую конвертацию между BaseNode/VectorStoreQuery и внутренними записями Qdrant.

## Новый синтезатор ответов (synth.py)

Добавлен асинхронный функционал synthesize() для генерации финального ответа на retrieved-ноды.
Поддерживает режимы: REFINE, COMPACT, TREE_SUMMARIZE, ACCUMULATE и др.
Включена кастомная логика стриминга и репакинга контекста (обход бага LlamaIndex #21740). Возвращает объект Tokens.

## Утилиты, асинхронность и сеть

_async.py: новый файл с утилитами Areturn, ayield, map_ctx() для унифицированной работы с async-генераторами и контекстными менеджерами.
fastembed.py: get_sparse_encoder() теперь принимает опциональный параметр timeout. При его указании результат оборачивается в стриминговый генератор. Изменён формат возврата на list[SparseEncoding].
util.py: упрощена обработка исключений в HTTP-транспорте, убрано создание лишних Future в raise_for_status(), исправлена работа min_max() с пустыми списками. Параметр транспорта переименован из v2 в aiohttp.
embed.py: исправлена логика обрезки текста по max_chars (теперь применяется только при явном указании), унифицированы типы семафоров и эмбеддингов.

# 0.5.x

## Встраивание и запросы (embed.py)

Добавлен параметр max_chars (по умолч. 100 000) для ограничения объёма текста в одном запросе к API эмбеддингов.
Стриминговый батчинг теперь динамически рассчитывает допустимый размер пакета через _get_token_trimmer, учитывая лимит символов.
Введены явные методы handshake() / handshake_sync() для инициализации клиента; добавлена проверка: если handshake не выполнен, _request сразу выбросит RuntimeError.
Улучшена обработка пустых списков текстов (return []). Дефолтные инструкции изменены с None на пустые строки.

## Qdrant Vector Store (qdrant.py)

Явные конфиги по умолчанию: dense_config и sparse_config теперь инициализируются готовыми объектами, а не None. Добавлена настройка modifier для sparse-конфига.
Поддержка множественных эмбеддингов: данные из node.metadata['embeddings'] теперь корректно записываются/считываются как список векторов, отдельно от одиночного node.embedding.
Рефакторинг запросов: _parse_query возвращает словарь {field_name: (vector, limit, threshold)}. Порог (threshold) применяется только к dense-векторам (как абсолютные значения), sparse-запросы остаются без порога.
Убран флаг _is_legacy: при обнаружении устаревшей конфигурации коллекции сразу выбрасывается ошибка, а не переключается внутренний режим.
Улучшена логика обновлений: явное дедуплицирование узлов, корректное определение размера вектора по первому элементу (с учётом множественных эмбеддингов).

## Утилиты и обработка ошибок (util.py, rerank.py)

raise_for_status расширена параметром eager: bool = False. При True ошибка выбрасывается немедленно (для синхронных ответов или закрытых стримов), не возвращая Future. Это устраняет необходимость вызова .result() в sync-коде.
Утилита min_max вынесена в util.py и используется для нормализации оценок при гибридном поиске.

## Работа с узлами (_nodes.py)

При преобразовании узла в словарь метаданных поле embeddings теперь явно исключается (metadata.pop('embeddings', None)), чтобы избежать дублирования векторов в payload.

## Конфигурация и зависимости

CI/CD пайплайн обновлён: изменён синтаксис триггеров тегов, добавлено условие запуска по изменению pyproject.toml, обновлены версии GitHub Actions, удалён twine (публикация идёт напрямую через OIDC).

# 0.4.x

Автоматическая пакетная обработка (Batching) эмбеддингов: В Embedder добавлен параметр latency. При значении > 0 включается автоматическая группировка запросов в пакеты на основе таймаута, размера батча и пула воркеров.

Унификация конфигурации повторных попыток (Retries):

- Поля max_retries переименованы в retries (OpenAiLike, QdrantVectorStore).
- Добавлена поддержка значения None для бесконечных повторов (в QdrantVectorStore).
- Введена валидация: отрицательные значения принудительно приводятся к 0.

Изменение семантики ретраев: Внутренний расчёт попыток изменён на 1 + retries. Теперь retries=3 означает 4 попытки (1 основная + 3 повтора), ранее количество совпадало с указанным числом.

Рефакторинг методов эмбеддинга.

# 0.3.x

## Обработка стримов токенов (_parsers.py)

- Добавлены новые асинхронные фильтры: wordify (разбивка потока на слова/пунктуацию), glue_reps (склеивание алфавитно-цифровых символов и повторов пунктуации), trim_repetitions_at_end (обрезка повторяющихся последовательностей в конце ответа).
- Улучшена совместимость no_think с AsyncIterable.

## HTTP-клиент и асинхронная инфраструктура (util.py, _env.py)

- Внедрён кастомный AiohttpTransport для безопасной работы aiohttp внутри httpx.
- Переписана система ретраев: добавлена поддержка пользовательских предикатов, точный контроль задержек и лимитов через tenacity.
- В конфиге появились переменные окружения: MAX_CONNECTIONS (по умолч. 100) и KEEP_ALIVE_TIMEOUT (по умолч. 15 сек).

## Embedding-сервис (embed.py)

- Единый интерфейс запросов: убраны раздельные методы для query/text, добавлена автоматическая подстановка инструкций.
- Внедрена поддержка параллельных запросов через семафоры (concurrency).
- Добавлена умная обработка ошибок и ретраев при 429 Too Many Requests или сбоях чтения.
- Стандартизирован парсинг ответов (Ollama, OpenAI) через Pydantic-валидацию.

## LLM-обёртка (openailike.py)

- Улучшена поддержка мультимодальных сообщений: корректная конвертация ImageBlock и нескольких текстовых блоков в формат OpenAI.
- Переписана логика tool calling: строгая валидация схем, явная настройка tool_choice (required/auto).
- Упрощена обработка параллельных вызовов инструментов и извлечения аргументов.

## Векторное хранилище Qdrant (qdrant.py, _nodes.py)

- Вынесена логика сериализации нод в _nodes.py (оптимизация payload, исключение embedding/relationships, использование pydantic_core).
- Добавлена настраиваемая именование полей для dense/sparse векторов.
- Улучшен гибридный поиск: нормализация оценок, корректная обработка пустых результатов, разделение запросов на dense/sparse.
- Объединены операции добавления/удаления в единый метод _ll_update.
- Добавлены низкоуровневые методы qretrieve и qquery для прямых запросов к Qdrant.

## Ранжирование (rerank.py)

- Полностью переписан класс Reranker: отделён от базового класса LlamaIndex, упрощена логика постобработки, улучшена интеграция с callback-менеджером.
